# Politique de sécurité et de confidentialité

## Signaler un problème

Ne pas ouvrir d’Issue publique lorsqu’un signalement contient :

- une vulnérabilité exploitable ;
- un secret, un mot de passe ou un jeton ;
- une donnée personnelle ou confidentielle ;
- une information permettant d’identifier une personne sans son accord.

Contacter directement le responsable ou un mainteneur afin d’organiser un traitement privé du signalement.

## Périmètre

Cette politique couvre les scripts, le mini-site GitHub Pages, les formulaires, les fichiers de configuration et les productions publiées dans ce dépôt.

## Règles préventives

- utiliser des données fictives, anonymisées ou explicitement autorisées ;
- ne jamais committer un fichier `.env`, une clé privée ou un jeton d’accès ;
- examiner les dépendances et scripts avant leur utilisation ;
- tester les liens et livrables avant publication ;
- retirer immédiatement toute donnée sensible découverte ;
- conserver une validation humaine avant toute publication.

## Réponse attendue

L’équipe accuse réception, évalue la gravité, limite l’exposition, corrige le problème et documente la résolution sans republier les informations sensibles.
