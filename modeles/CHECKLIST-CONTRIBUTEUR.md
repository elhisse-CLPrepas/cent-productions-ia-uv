# Checklist du contributeur

## Avant la Pull Request

- [ ] L’Issue est qualifiée et m’est affectée.
- [ ] La fiche respecte le modèle officiel.
- [ ] Le nom du fichier respecte `PXXX-categorie-titre-court.md`.
- [ ] Le besoin, le public et l’objectif sont clairement définis.
- [ ] Le workflow humain–IA est expliqué.
- [ ] Les prompts ne contiennent aucune donnée sensible.
- [ ] Le livrable ou son lien est disponible.
- [ ] Les faits importants et les liens ont été contrôlés.
- [ ] Les sources et les droits sont indiqués.
- [ ] Les limites sont signalées.
- [ ] Les preuves sont accessibles.
- [ ] L’orthographe et la mise en forme ont été relues.
- [ ] La Pull Request est liée à l’Issue.
