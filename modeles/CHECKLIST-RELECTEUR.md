# Checklist du relecteur

## Contrôle de la contribution

- [ ] Le besoin réel et le public sont identifiés.
- [ ] Le résultat répond au besoin annoncé.
- [ ] La méthode peut être comprise et réutilisée.
- [ ] Le rôle de l’IA et celui de l’humain sont distincts.
- [ ] Les affirmations importantes sont vérifiées.
- [ ] Les liens et le livrable fonctionnent.
- [ ] Les sources sont fiables et correctement citées.
- [ ] Les droits d’utilisation sont compatibles.
- [ ] Aucune donnée sensible n’est exposée.
- [ ] Les limites sont clairement présentées.
- [ ] Les preuves permettent de contrôler la réalisation.
- [ ] Une seconde review est demandée si le contenu est sensible ou à fort impact.

## Avis

- [ ] À corriger
- [ ] Validable après corrections mineures
- [ ] Validé
