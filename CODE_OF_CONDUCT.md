# Code de conduite

## Notre engagement

Nous voulons offrir un espace d’apprentissage accueillant, respectueux, inclusif et sûr. Chaque personne doit pouvoir participer indépendamment de son niveau technique, de son expérience ou de son parcours.

## Comportements attendus

- communiquer avec respect et bienveillance ;
- formuler des critiques précises, constructives et centrées sur le travail ;
- accueillir les questions des débutants sans jugement ;
- citer les auteurs, les sources et les contributions ;
- respecter la confidentialité et le consentement ;
- reconnaître les erreurs et contribuer à leur correction ;
- distinguer clairement les productions de l’IA des décisions humaines.

## Comportements inacceptables

- harcèlement, intimidation, discrimination ou attaque personnelle ;
- publication de données personnelles ou confidentielles ;
- plagiat, fausse attribution ou dissimulation volontaire des sources ;
- contenu illégal, dangereux ou trompeur ;
- pression visant à contourner une review ou une règle de validation ;
- utilisation du projet à des fins promotionnelles sans valeur pédagogique.

## Application

Les incidents doivent être signalés de manière privée au responsable du projet. Les mainteneurs peuvent demander une correction, masquer un contenu, fermer une contribution ou limiter la participation lorsqu’une règle n’est pas respectée.

Le responsable du projet, Prof. Abderrahman EL HISSE, arbitre les situations graves ou les désaccords structurants.
