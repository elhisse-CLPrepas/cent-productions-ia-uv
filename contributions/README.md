# Contributions

Ce dossier accueille les fiches validées ou en cours de review, classées par catégorie.

Chaque fiche doit être créée à partir du modèle officiel et porter un nom conforme à `PXXX-categorie-titre-court.md`.

Les catégories 1, 2, 3, 4 et 8 sont ouvertes pendant le pilote. Les autres sont préparées pour l’extension du catalogue.
